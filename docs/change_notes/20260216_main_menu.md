# Main Menu and Scene Management

**Date:** 2026-02-16
**Phase:** E - Main Menu and Scene Management

## Summary

Added a MainMenu screen and scene management so the game no longer starts directly into gameplay. Players now see a title screen ("KOBAYASHI MARU / TACTICAL SIMULATION") with Start and Sound toggle buttons. The PauseOverlay's Quit button now properly returns to the main menu.

## Changes

### New Files

- **`src/ui/screens/MainMenu.ts`** - Full-screen main menu with LCARS-themed UI:
  - Title "KOBAYASHI MARU" (orange) and subtitle "TACTICAL SIMULATION" (blue)
  - "START SIMULATION" button that triggers game start
  - "SOUND: ON/OFF" toggle button connected to AudioManager
  - `show()`/`hide()`/`isVisible()` visibility methods
  - `setOnStart(callback)` for wiring start button
  - Container zIndex 999 (below pause overlay at 1000)
  - Follows same pattern as PauseOverlay for button creation/hover effects

- **`src/__tests__/MainMenu.test.ts`** - 14 tests covering:
  - Initialization, container structure, zIndex
  - show/hide visibility toggling
  - Start button callback firing
  - Sound toggle calling AudioManager.toggleMute()
  - Destroy cleanup

### Modified Files

- **`src/core/Game.ts`**:
  - Added `setupMainMenu()` - creates and shows MainMenu on init
  - Added `startGame()` - hides menu, calls `gameplayManager.init()`, starts loop
  - Added `quitToMenu()` - clears gameplay, shows menu, pauses loop
  - `init()` no longer auto-calls `gameplayManager.init()` (shows menu instead)
  - PauseOverlay quit callback now calls `quitToMenu()` instead of logging
  - InputRouter QUIT action now calls `quitToMenu()`

- **`src/core/managers/GameplayManager.ts`**:
  - Added `stopAndClear()` method - unsubscribes events, clears entities, resets managers/state back to MENU (used by quit-to-menu flow)

- **`src/core/services/ServiceContainer.ts`**:
  - Added `mainMenu: MainMenu` to ServiceRegistry type map

- **`src/core/bootstrap/GameBootstrap.ts`**:
  - Added MainMenu service registration in `registerUIServices()`

- **`src/ui/index.ts`**:
  - Added `MainMenu` export from `./screens/MainMenu`

- **`src/__tests__/gameOrchestration.test.ts`**:
  - Added `mainMenu` mock to service map
  - Added `stopAndClear` mock to mockGameplayManager
  - Added `getState` mock to mockLoopManager
  - Updated init test: `gameplayManager.init` is no longer called during `Game.init()` (menu shows instead)

## Scene Flow

```
Game.init() -> setupMainMenu() -> MainMenu.show()
     |
     v
User clicks "START SIMULATION"
     |
     v
startGame() -> MainMenu.hide() -> gameplayManager.init() -> loopManager.start()
     |
     v
[PLAYING]  <-- pause/resume/restart work as before
     |
     v
User clicks "QUIT" from PauseOverlay
     |
     v
quitToMenu() -> clear entities -> reset state -> MainMenu.show() -> loopManager.pause()
     |
     v
Back to MainMenu (user can start a new game)
```
